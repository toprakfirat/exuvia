# examples

Sample avatars and assets you can drop into the exuvia wizard to try the
app without sourcing your own model first.

## avatar.glb

A rigged GLB with idle / wave / dance / point / blowkiss / annoyed
animation clips. Sourced from [Mixamo](https://www.mixamo.com) (Adobe),
used in accordance with the
[Mixamo terms of use](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html)
— Mixamo characters and animations are free to use, modify, and bundle
in any project, commercial or otherwise.

To use it:

1. Open exuvia, click **+ new avatar** in the picker
2. Drop `examples/avatar.glb` onto the file box
3. Continue through the wizard — sensible defaults will fill in for you

The wizard auto-tags common clip names (wave, dance, idle…) so the
avatar will gesture correctly out of the box.
